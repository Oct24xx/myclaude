## 代码

行内代码适合展示简短的命令或变量，例如 `myclaude.css`、`font-family` 和 `background-color`。

```css
:root {
    --bg-color: #faf9f5;
    --font-color: #141413;
    --accent-color: #d97757;
}

body {
    color: var(--font-color);
    background: var(--bg-color);
}
```

```javascript
function greet(name) {
    return `Hello, ${name}!`;
}

console.log(greet("MyClaude"));
```
